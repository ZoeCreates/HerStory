# HerStory

A native iOS app that shows a daily quote from an inspiring woman, chosen from the topics you pick. Work in progress.

## Features

- Onboarding and topic selection (confidence, career, study, courage, resilience)
- A daily quote picked by date from your chosen topics
- Home screen and lock screen widgets that share your topics with the app through an App Group

## Built with

Swift, SwiftUI, WidgetKit, Xcode

## Run it

Open `HerStory.xcodeproj` in Xcode, select the `HerStory` scheme, and run it on an iOS Simulator.

## Status

The Saved tab is a placeholder, and the quote library is a small built-in sample.
